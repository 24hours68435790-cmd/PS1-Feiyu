# Companion code — strategic disclosure under AI-assisted valuation

This folder replaces the course template's class LLM example (a synthetic logit
cognitive-hierarchy pilot for Jia et al.) with the computational artifact for my
own proposal. The replaced files are listed at the bottom.

## Run it

```bash
pip install -r requirements.txt
python src/run_experiments.py           # ~4 s, writes results/*.csv and both figures
python -m unittest discover -s tests    # 15 tests, each one a claim the paper makes
```

Deterministic: fixed seeds, no wall-clock, no network, no hidden state.

**The run asserts before it reports.** `verify_space_replication()` re-implements
JavaScript's `mulberry32` PRNG in Python and must reproduce the four cases logged
from the deployed browser Space — same draw (θ = 2, k = 0.5), same ε sequence,
same prices to the cent — or the script fails. The game and the notebook cannot
silently disagree.

## The two rules

Following Prof. Zhang's Week 2 note — *"compare fixed and revisable evaluator
rules in the same game; record deviation gains as well as disclosure accuracy"*:

- **COMMITTED** — the announced allowance `m̄` is the one followed, always.
- **REVISABLE** — `m̄` is still announced, but after round 1 the evaluator
  follows `m̄ + λ·g₁`, where `g₁ = (s₁ − y₁) − m̄`.

Identical draws, identical firm actions, identical tree. Only the rule differs.

## Evidence status

Every output here is a simulated output of my own model. Nothing is evidence
about human behaviour, about any real AI system, or about any real firm. Best
responses are computed against a *posted* rule, not solved as an equilibrium
fixed point. The convex manipulation cost is a modelling assumption inherited
from Fischbacher & Föllmi-Heusi as motivation, never estimated.
