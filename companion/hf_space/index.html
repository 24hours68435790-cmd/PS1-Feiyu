When the Model Becomes the Target

A two-period teaching game: a firm that knows it is being scored chooses between real effort and window-dressing; a committed evaluator and a revisable evaluator price the same report. Coarse by design. Client-side only — nothing is sent anywhere.
Feiyu Li (fl140) · COMSCI/ECON 206, Duke Kunshan University · PS1 v2.

1 · Draw and setup

Random draw

The seed makes every run reproducible: same seed → same private type. Record it with your results.

Your private type (the evaluator cannot see this)

True quality θ = – (drawn from {1, 2, 3})

Manipulation-cost type k = – (drawn from {0.5, 1, 2}; cost of window-dressing is k·m²)

Which evaluator is in force?

Both are always computed and displayed on the identical draw, so the evaluator is the only variable. The one in force determines your recorded payoff.

Evaluator parameters — the two knobs the research sweep varies

Outcome noise σ — how noisy the realised outcome is: ε ∈ {−σ, 0, +σ}

The announced allowance is m̄ = 1. Once σ > m̄ the revisable rule can price an honest firm worse than the committed rule would. To see it: seed 2, σ = 2, play a = 1, m = 0 twice. You inflate nothing and still get priced at 2.00 against a true value of 4.00, where the committed rule would have said 3.00. (Seed 2026 draws ε = 0 first, so it never shows this — which is exactly the blind spot the Week 2 version had.)

Memory strength λ — how hard round 2 discounts last round's residual

In the research sweep, deterrence stops improving past λ ≈ 0.5 while pricing accuracy keeps degrading — so this default of 1.0 is optimal for neither. It is kept as the default only because it is what the Week 2 version shipped with.

Defaults reproduce the Week 2 version exactly. At σ = 0.5, λ = 1 every price this page produces is bit-identical to the original, which is what lets the research notebook assert replication against it.

4 · The complete rules (nothing is hidden)

Complete rule table for the two-period game
ElementDefinition as implemented
ActorsFirm (you) and Evaluator. Investors allocate mechanically at the posted price and are not a strategic player.
Private typeθ ∈ {1, 2, 3} uniform (true quality); k ∈ {0.5, 1, 2} uniform (manipulation-cost type). Both drawn once and fixed for both rounds.
Firm actionsa ∈ {0, 1, 2} productive effort; m ∈ [0, 2] window-dressing.
Reports = θ + a + m
True valuev = θ + a — window-dressing does not create value.
Realised outcomey = v + ε, with ε ∈ {−σ, 0, +σ} uniform, σ set in section 1 (default 0.5). Revealed after the price is posted.
Committed evaluatorp = max(0, s − m̄) with announced m̄ = 1. The announced rule is the followed rule: it never uses this firm's history.
Revisable evaluatorRound 1: identical to committed. Round 2: p = max(0, s₂ − m̄ − λ·g₁) where g₁ = (s₁ − y₁) − m̄ is last round's residual inflation and λ is set in section 1 (default 1). m̄ is still what was announced — the followed rule has moved away from it.
Firm payoffπ = p − 0.5·a − k·m² (price minus effort cost minus convex manipulation cost).
Social welfareW = v − k·m² — real value created, net of resources burnt on manipulation.
Mispricing|p − v|, reported per round as the allocative distortion.
HorizonTwo rounds, then the game ends. Reset draws a fresh θ, k and empties the history.
Invalid inputA custom m that is non-numeric, negative, or above 2 is rejected: an error message is shown, the round does not advance, and no state changes.

5 · What this artifact does not show

  • It is a teaching artifact, not the research model. It plays one fixed parameterisation on a coarse grid; it does not solve for equilibrium. Equilibrium claims belong to the OpenSpiel/CFR version, not to anything you can see here.
  • No output here is evidence for H1–H3. Those hypotheses remain anticipated, not obtained.
  • The convex cost k·m² is a modelling assumption, not an elicited behavioural fact. No human subject has been run.
  • Discretising θ and m has not been shown to preserve the equilibrium of a continuous game.
  • The revisable evaluator infers inflation from a noisy signal (ε), so it can penalise an honest firm that drew badly. You can now trigger this deliberately with the σ control; the research notebook measures how often it happens. Seeing it once here is a demonstration, not the measurement.
  • The noise here is coarser than in the research model, and the rates differ. This page draws ε from three points {−σ, 0, +σ}, so for σ > m̄ an honest firm is mis-priced relative to commitment in 2/3 of draws. The notebook draws ε ~ Uniform(−σ, σ) and reports (σ − m̄)/σ, which is 1/2 at σ = 2. Same mechanism and same threshold σ* = m̄; different frequency. Quote the notebook's number, not this page's.
  • The revisable evaluator has not been tested against a firm deliberately building a misleading history over a longer horizon.
  • All quantities are simulated. Nothing here is a valuation of, or evidence about, any real firm.
